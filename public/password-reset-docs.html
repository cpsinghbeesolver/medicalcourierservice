🔐 Password Reset API Documentation

Medical Courier Services - Forgot Password & OTP Verification

📱 Two Methods Available:

  • Method 1: Email Reset Link - Sends a secure link that expires in 60 minutes (Best for web applications)
  • Method 2: OTP Code - Sends a 6-digit code that expires in 15 minutes (Best for mobile applications)

🔒 Security Features:

  • HIPAA-compliant with full audit logging
  • Tokens are hashed in database using bcrypt
  • One-time use tokens/OTPs (cannot be reused)
  • Automatic cleanup of used/expired tokens
  • Rate limiting recommended for production
